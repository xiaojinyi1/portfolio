# 个人作品集网站 — 设计稿

日期：2026-10-25
状态：待用户确认

## 1. 这个网站是干什么的

课堂上，站在讲台前，把这个网址打开，然后顺着往下讲。

使用者是我自己。听众是老师和同学。作品是过去一年半里做的几个网站，现在都还是本地文件夹，展示前才会部署上线。所以这个网站要解决的不只是"好看"，而是**当着几十个人的面，能让讲述不掉链子**。

两条必须成立的：
- 我把作品扔进去，网站自己给我写一段能直接念出来的中文介绍；
- 讲的时候不用切窗口、不用现场配置，一个浏览器标签页走到底。

**什么叫成功**：从打开首页到讲完第四个作品，全程不需要我现场组织语言，也不需要手忙脚乱地找链接。

**什么叫失败**（技术上跑起来了也算失败）：
- 生成出来的文字是"本项目旨在通过先进技术打造卓越用户体验"这种套话——那我宁可不写；
- 投影仪上动效掉帧、或者首次加载白屏；
- 上传一个作品要开命令行；
- 课堂网络不好就整站打不开。

## 2. 已经定下来的

**版式：A「衬线索引」**。不做大图瀑布流。作品名本身就是列表项，靠字号、字距和留白撑住画面。鼠标移到标题上时，封面图跟着光标飘出来——这是参考站的做法，也是没有大图时唯一的"画面感"来源。

**图片动效**（已确认手感）：
- 进入视口前：`transform: scale(0.96)`、`opacity: 0`
- 进入视口：放大到 1 并淡入，780–900ms，`cubic-bezier(0.22, 1, 0.36, 1)`
- 同组图片之间错开 90ms
- 鼠标悬停：`scale(1.015)` + 柔和外阴影
- 用 IntersectionObserver，`threshold: 0.15`，进场后立即 `unobserve`，不挂滚动监听
- 只动 `transform` 和 `opacity`
- 尊重 `prefers-reduced-motion: reduce`
- 应用范围：项目卡片截图、封面图、详情页配图

**运行时：分层混合**（用户选定）。能静态托管的就静态托管，需要后端的作品才起子进程，线上地址默认直嵌、可选镜像到本地。理由：一堂课上不该让四个作品共用一个"全押进程"的风险，坏一个不能拖垮全场。

**生成文字用 DeepSeek**（`https://api.deepseek.com/chat/completions`，模型 `deepseek-chat`）。Key 已实测可用。

**视觉语言**（从参考站提取的硬约束）：
- 底色 `oklch(0.1292 0.005 262.04)`，卡片面 `oklch(0.1468 0.01 262.04)`，分隔线 `oklch(0.2484 0.018 262.04)`
- 正文灰蓝 `oklch(0.7716 0.028 262.04)`，主文字 `oklch(0.9366 0.027 262.04)`
- 显示字体 Instrument Serif（中文回退思源宋体 / Noto Serif SC），UI 字体 Inter，数字与标签用等宽
- **不加任何强调色，不做浅色模式，不用渐变，不用圆角卡片**
- 交互克制：悬停只做透明度、位移、极小的缩放

## 3. 我拿的主意（可以否决）

这几条是我按"课堂上别出事"的原则定的，不是你要求的：

**用 Next.js 15（App Router）+ TypeScript + 手写 CSS**。不用 Tailwind——这套设计是逐字调字距和行高的，写在 CSS 变量里更好改。不用数据库，项目数据存 `data/projects.json`，作品文件落 `data/sites/<slug>/`。理由：单用户、作品数量个位数，引入 SQLite 只会多一个 Windows 原生编译的坑。

**上传不是一种方式，是四种来源，都进同一个模型**。这是"上传流程要完善"的核心：
- **zip / 文件夹**（静态产物，或者整个仓库）
- **静态网址**（作品已经部署在线上了，我只想贴个 URL）
- **本机目录路径**（作品本来就在我电脑上，别复制、别构建，直接注册）

**每个作品 = 一个本地端口。** 这一条把上面几种来源和"要真跑"的诉求统一了：

- 静态产物：站内起一个只读的静态监听，端口指向那个目录。不塞进 `public/` 的子路径——子路径会让"根绝对路径引用"的站点全挂（`/assets/x.png` 变成 404），而独立端口下它自己就是根，一个字节都不用改。
- 需要后端的仓库：起子进程（`npm start` / `node server.mjs`），分配端口，等健康检查通过，记状态。
- 线上静态网址：默认直接 iframe 那个 URL；可选"镜像到本地"，把 HTML/CSS/JS/图片抓一份下来存成本地静态作品（断网也能讲）。

详情页和内嵌预览统一是 `iframe` 指向 `http://127.0.0.1:<port>/`。跨源无所谓，我们不读它的 DOM。

**理由**：课堂网络不可靠，也不能指望现场构建。独立端口是唯一同时兼容"静态产物 / 带接口的真服务 / 线上地址"三者的做法，而且出问题只影响单个作品。

**启动策略**：默认在作品集启动时把所有进程型作品预热起来（避免课上演到一半等冷启），后台有"全部启动 / 全部停止"和每个作品的状态灯（未启动 / 启动中 / 已就绪 / 失败 + 原因）。

**自动生成只在"上传之后"发生一次**，生成结果进编辑框，我改完点发布才上是非公开草稿。生成失败或超时就保留空介绍，允许手写。

**截图不自动截屏**。不引入 Playwright（要下浏览器内核，一百多兆，离线风险大）。改为：上传后自动扫描站点里的图片，按文件体积/尺寸挑前几张做候选，我在后台勾选、排序、补拍自己的截图。

**后台 `/admin` 用单口令**（环境变量里配一个），只在本机用，不做注册登录。

**运行方式：本机 `npm run build && npm start`，投影仪接笔记本**。不部署到 Vercel——那边文件系统只读，上传功能会直接坏掉。

## 4. 页面

**`/` 首页**
1. 固定顶栏：名字（等宽、字距放宽）+ Index / About / Work / Contact
2. 右侧竖向滚动进度数字 `0.00 → 1.00`
3. 首屏：`你好，我是 ___，做前端和交互。` ——衬线、斜体强调、负字距
4. About 段落（三五行，第一人称）
5. Selected work：一行一个作品，衬线标题 + 年月，悬停漂浮封面
6. 页脚：邮箱 / GitHub / 一行落款

**`/work/[slug]` 详情页**
1. `CASE STUDY · 01` 小标签
2. 衬线大标题
3. 自动生成的两段介绍（第一段讲是什么、为谁做；第二段讲难点和取舍）
4. 四格事实：时间 / 角色 / 技术 / 状态
5. 截图，每张带一行说明，进场走 reveal 动效
6. 底部：`打开网站 ↗` 与内嵌预览（iframe 指到该作品的本地端口；端口没起来就显示状态和"重试"，不是白框）
7. 上一件 / 下一件

**`/admin`**
1. 口令登录
2. 项目列表：草稿 / 已发布 / 时间
3. 新建：四选一来源（zip / 文件夹 / 静态网址 / 本机路径）→ 识别 → 起端口 → 预览
4. 每个作品一张运行状态卡：端口、模式（静态 / 进程 / 外链）、状态灯、最近日志尾部
5. 等待生成（有进度状态，不会白屏）
6. 编辑：标题、日期、介绍、四格事实、截图选择与排序、是否公开
7. 发布 / 取消发布 / 删除
8. 顶栏两个总开关：全部启动 / 全部停止

## 5. 数据模型

```ts
type Runtime =
  | { kind: "static"; dir: string }                                  // 本地目录，站内静态监听
  | { kind: "process"; cwd: string; start: string; healthPath?: string } // 起子进程，反代到端口
  | { kind: "remote"; url: string; mirrored: boolean };              // 线上地址，或镜像后的本地副本

type Project = {
  slug: string;            // 由标题生成，冲突时追加序号
  title: string;
  date: string;            // "2025.06"
  intro: string[];         // 2 段，自动生成后人工可改
  facts: {                 // 四格
    time: string;
    role: string;
    stack: string;
    status: string;
  };
  images: { src: string; caption: string; alt: string }[];
  note?: string;           // 可选：我自己写一句"这个项目最难的地方"，喂给生成器
  runtime: Runtime;        // 作品怎么跑
  port?: number;           // 分配到的本地端口
  sourceLabel: string;     // "上传 zip" / "本机目录" / "静态网址"，后台显示用
  published: boolean;
  createdAt: string;
  order: number;
};
```

## 6. 生成那段文字（这是最容易做砸的地方）

**喂给模型的素材**：首页 `<title>`、meta description、所有 h1–h3 的文本、可见正文前 2000 字、文件清单（用来判断技术栈，比如看到 `package.json` 依赖、`.php`、`wp-content`）、zip 里若有 `README.md` 或 `docs/` 文本则一并喂进去、以及我在后台上传时填写的那一句 `note`（"这个项目最难的地方是……"）。

> 为什么要有 `note`：第二段写"最费劲的地方和做过的一个取舍"，这些信息在 HTML 里根本不存在。只靠页面文本，模型只能写空话——那正好是 §1 定义的失败。所以留一个可选的一句话输入框；它不填，就退化成只写第一段。

**输出**：严格 JSON

```json
{
  "intro": ["第一段", "第二段"],
  "facts": { "time": "", "role": "", "stack": "", "status": "" }
}
```

**提示词要求**：
- 中文，第一人称，口语但克制
- 第一段：这东西是什么、给谁用、解决什么具体的麻烦
- 第二段：做的时候最费劲的地方，以及做过的一个取舍
- 每段 2–4 句，不写小标题，不用列表
- 不写"本项目旨在""赋能""打造""一站式""深度融合"这类词
- 不确定的不要编：技术栈只写从文件里能看出来的
- 不提及自己是 AI

**兜底**：模型超时或返回坏 JSON，就重试一次；仍失败则存空介绍，后台提示"生成失败，请手写"，绝不把半截 JSON 塞到页面上。

## 7. 约束

- Windows 本机，Node 24 已装
- API key 放 `.env.local`，不进 git；`.gitignore` 里要有 `.env.local` 和 `.superpowers/`
- **PowerShell 和 curl 直连 `api.deepseek.com` 会 TLS 失败，必须用 Node 的 `fetch`**（已实测：Node fetch 返回 200）
- 上传的 zip 需要防路径穿越（解压时校验目标路径必须在项目目录内）
- 单次上传体积上限先定 50MB

## 8. 不做的

- 不做多用户、评论、点赞
- 不做博客 / 文章系统（参考站有，但这个网站的用途是课程展示）
- 不做浅色模式
- 不做 SEO、不做 sitemap、不做分析统计
- 不部署上云
- 不做移动端极致适配——手机上能看、不崩就行，优先保证投影仪 16:9 的效果

## 9. 验收标准

1. 四种来源（zip、文件夹、静态网址、本机目录）都能在 `/admin` 里走完：识别 → 起端口 → 预览真的能打开 → 出草稿，介绍文字读得通、没有套话
2. 改两句话 → 发布 → 首页列表出现，悬停有漂浮封面
3. 点进详情页，滚动时图片按既定动效进场，投影分辨率下不掉帧
4. 断网状态下，首页、详情页、静态与镜像作品仍能打开；进程型作品在依赖已装好的前提下也能跑
5. 坐在后排的人能看清标题（最小标题字号不低于 20px）
6. 关掉作品集再开一次，端口不冲突、没有残留子进程

## 10. 复核后补的几条（针对实施时才会踩到的坑）

**导入时的识别顺序**（每一步都要给明确失败提示，不能白等）：找入口 `index.html` → 根目录 → `dist/` → `build/` → `public/` → `out/`。找到就按静态模式跑。找不到但 `package.json` 里有 `start`/`dev`/`serve` 脚本 → 建议进程模式。两者都没有 → 直接说"这个包里没有能运行的入口"，并把检测到的文件树列出来。

**进程模式的三条护栏**：端口从 4300 起顺延，占用就换下一个；启动有超时（默认 60 秒，`npm install` 单独一步、上限 5 分钟、日志尾巴实时显示）；子进程必须随作品集一起退出——Windows 上要 `taskkill /pid <pid> /T /F`，否则 node 孙进程会残留并占着端口，下次启动全挂。

**镜像扫描器要收边界**：只跟同源链接、最多 60 个页面或 20MB、深度 2、单请求 5 秒超时。遇到 `X-Frame-Options: DENY` 或 CSP `frame-ancestors 'none'` 就别镜像了，退回"直嵌外链 + 二维码"，否则嵌进去是一片空白。

**iframe 一律加** `sandbox="allow-scripts allow-same-origin allow-forms allow-popups"`，并在外面套"加载失败 / 端口未就绪"的状态提示，避免白框。

**讲台用翻页笔就加键盘导航**：`←`/`→` 切上一件下一件，`Esc` 回首页，`F` 全屏。不需要滚动吸附——那会改掉整页的滚动和 reveal 逻辑。

**局域网访问作为可选项**：默认只在本机 `localhost:3000`。老师同学要在自己设备上打开时，改用 `npm start -- -H 0.0.0.0` 并放行防火墙端口，README 里写清楚。注意：这种情况下 `127.0.0.1:<port>` 的内嵌预览在别人设备上不成立，得换成本机局域网 IP。

**`/admin` 要有"没配 Key"的可见状态**：`.env.local` 里没有 `DEEPSEEK_API_KEY` 时，上传仍然能存项目，但生成那一步显示"未配置 Key，请手写介绍"，而不是转圈到超时。
